# Credit Card Loan Risk Analysis and Classification

Welcome to the repository for the Classification Analysis of the German Credit Card Dataset. This project utilizes Decision Tree and Naïve Bayes machine learning models to explore how feature selection influences the accuracy, sensitivity, and specificity of creditworthiness classification.

---
## Project Overview

This project investigates the German Credit Card Dataset, containing 1000 observations across 20 numerical and categorical variables. The main goal is to classify creditworthiness effectively, exploring the impact of feature selection on model performance. Decision Tree and Naïve Bayes models were evaluated before and after feature selection to measure changes in performance metrics, emphasizing the importance of informed feature selection in predictive modeling.

---
### Tasks

1. Data Preparation: Ensured the dataset had no missing values or unnecessary encoding.
2. Data Exploration: Conducted descriptive statistics, box plots, scatter plots, and histograms to understand feature distributions and relationships.
3. Feature Selection: Employed correlation analysis, one-way ANOVA, and chi-square tests to identify statistically significant features.
4. Predictive Modeling: Built baseline and post-feature selection models using Decision Tree and Naïve Bayes classifiers, comparing performance through accuracy, sensitivity, and specificity metrics.

---
### Skills Demonstrated

1. Data Cleaning and Preprocessing: Techniques to prepare data for modeling, including checking for missing values and encoding categorical variables.
2. Exploratory Data Analysis (EDA): Utilization of visualizations (box plots, scatter plots, histograms) and descriptive statistics to uncover data insights.
3. Statistical Analysis: Application of correlation analysis, one-way ANOVA, and chi-square tests for feature selection.
4. Machine Learning: Implementation and evaluation of Decision Tree and Naïve Bayes classifiers, interpreting confusion matrices, and assessing model performance metrics (accuracy, sensitivity, specificity).
5. Model Optimization: Understanding the effects of feature selection on predictive accuracy and exploring strategies for further model enhancement, such as addressing class imbalance.
